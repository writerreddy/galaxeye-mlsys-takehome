# models/

- `land_use_classifier.joblib` — the trained model artifact (a scikit-learn
  `Pipeline`-free dict of `{pipeline, classes, trained_at, feature_length,
  model_version, n_train_samples, n_val_samples}`), loaded by the app at
  startup. Checked into the repo so the API runs out of the box without
  requiring a training step first. Regenerate it any time with
  `python scripts/train.py` (deterministic — same result every run).
- `confusion_matrix.png` — generated by `python scripts/evaluate.py`
  against the held-out `eval_set/`. Not required for the app to run;
  it's a visual aid for discussing model quality.
